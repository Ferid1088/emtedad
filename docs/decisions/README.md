# Architecture Decision Records

Use an ADR for decisions that materially affect data compatibility, security,
deployment, domain boundaries, retrieval behavior, or reproducibility.

## Status values

- Proposed
- Accepted
- Superseded
- Rejected

## Required sections

1. Title
2. Status and date
3. Context
4. Decision
5. Consequences
6. Alternatives considered
7. Supersedes / Superseded by, where applicable

Do not use ADRs to rewrite approved Ayin or Manasek content. Those changes
belong to the editorial versioning workflow.
